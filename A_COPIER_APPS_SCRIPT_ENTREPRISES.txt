CODE CORRIGE A RECOLLER DANS GOOGLE APPS SCRIPT (SHEET ENTREPRISES)
========================================================

L'erreur précédente ("Cannot read properties of null (reading 'getSheets')")
vient du fait que le script n'était pas lié à la feuille. Le code ci-dessous
cible directement le Sheet par son ID, ça règle le problème.

1. Ouvre le projet Apps Script que tu as déjà créé (celui avec l'URL /exec
   que tu m'as donnée), ou ouvre le Sheet et refais Extensions > Apps Script.

2. Sélectionne TOUT le code existant (Ctrl+A) et supprime-le (Suppr)

3. Colle exactement le code ci-dessous (entre les lignes ===)

4. Clique sur l'icône disquette (Enregistrer)

5. Clique sur "Déployer" > "Gérer les déploiements"
   - Clique sur le crayon (Modifier) à côté du déploiement existant
   - Version : "Nouvelle version"
   - Clique "Déployer"
   (l'URL /exec reste la même, pas besoin de me la redonner)

6. Renvoie-moi un message "c'est corrigé" et je testerai à nouveau.

========================================================
CODE (tout ce qui suit, jusqu'à la ligne de fin) :
========================================================

const SHEET_ID = "10fuGeT_4Rn2QzfecfMniQi-i-399hwAX4eINcctpLeE";

function doPost(e) {
  const sheet = SpreadsheetApp.openById(SHEET_ID).getSheets()[0];

  let data;
  try {
    data = JSON.parse(e.postData.contents);
  } catch (err) {
    return ContentService.createTextOutput(
      JSON.stringify({ ok: false, error: "invalid_json" })
    ).setMimeType(ContentService.MimeType.JSON);
  }

  sheet.appendRow([
    new Date(),
    data.entreprise || "",
    data.secteur || "",
    data.contact || "",
    data.fonction || "",
    data.email || "",
    data.telephone || "",
    data.effectif || "",
    data.domaine || "",
    data.format || "",
    data.delai || "",
    data.message || "",
    data.source || ""
  ]);

  return ContentService.createTextOutput(
    JSON.stringify({ ok: true })
  ).setMimeType(ContentService.MimeType.JSON);
}
